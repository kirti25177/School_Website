📚 Responsive School Website
📌 Project Overview
This project is a responsive school website designed using HTML, CSS, and JavaScript. The goal is to create a modern, user-friendly, and mobile-friendly website that provides essential information about a school.
The website adjusts seamlessly across different devices such as desktops, tablets, and smartphones.

🎯 Features
✅ Fully responsive design (mobile, tablet, desktop)
✅ Clean and modern UI
✅ Navigation bar with smooth scrolling
✅ Home, About, Courses, Gallery, and Contact sections
✅ Interactive elements using JavaScript
✅ Contact form (basic frontend validation)
✅ Image gallery for school activities
✅ Easy-to-read layout and typography

🛠️ Technologies Used
HTML5 – Structure of the website
CSS3 – Styling and responsiveness (Flexbox/Grid, Media Queries)
JavaScript (JS) – Interactivity and dynamic behavior
